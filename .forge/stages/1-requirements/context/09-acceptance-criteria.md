# 09 - Acceptance Criteria (Detailed)

## AC-01: Dry-run completes without error

```bash
conda activate snakemake9
snakemake -s Snakefile --configfile examples/inputs/downsampled/repeat_mapping_SE_small.yaml -n
snakemake -s Snakefile --configfile examples/inputs/downsampled/repeat_mapping_PE_small.yaml -n
```
Expected: No errors, rule DAG printed.

## AC-02: Downsampled SE pipeline matches CWL reference

Run:
```bash
snakemake -s Snakefile --configfile examples/inputs/downsampled/repeat_mapping_SE_small.yaml --profile profiles/tscc2_snakemake9
```

Compare (modulo tie-breaking differences):
```bash
diff <output>/<dataset>.nopipes.tsv <expected_reference>.nopipes.tsv
diff <output>/<dataset>.withpipes.tsv <expected_reference>.withpipes.tsv
```

Expected: Files are identical or differ only in rows where random tie-breaking applies.

Note: Reference outputs for the EXAMPLE_SE data must first be generated by running the CWL pipeline on the downsampled data (Step 2 in the PRD).

Same as AC-02 but for PE data.

## AC-06: All 25 scatter jobs complete and merge correctly

Verify all 25 prefix jobs produce non-empty output:
```bash
ls -la <output_dir>/<barcode>/*combined_w_uniquemap.rmDup.sam | wc -l  # should be 25
```

Verify merged .parsed file line count matches sum of per-prefix .parsed files (minus duplicate headers).

## AC-07: PE config validation — missing barcode2

Run:
```bash
snakemake -s Snakefile --config se_or_pe=PE dataset=test barcode1r1FastqGz=/dev/null -n 2>&1 | grep -i "error\|missing\|required"
```
Expected: Error message before any rules run, mentioning barcode2 fields.

## AC-08: SE config validation — extra PE fields

Run with a config containing both SE mode and barcode2 fields.
Expected: Error message before any rules run, mentioning unexpected barcode2 fields.

## AC-09: Downsampled dataset coverage

```bash
# Check all 25 prefixes have ≥100 reads in the FASTQ
zcat examples/inputs/downsampled/EXAMPLE_SE.IP.umi.r1.fqTrTr.sorted.fq.gz | \
  grep "^@" | grep -oP '_[A-Z]{2}' | sort | uniq -c | awk '$1 < 100 {print "FAIL:", $0}'
```
Expected: No output (all prefixes have ≥100 reads).

## AC-10: BAM reads exist in FASTQ

```bash
# Read names in BAM must be subset of read names in FASTQ
samtools view examples/inputs/downsampled/EXAMPLE_SE.IP.umi.r1.fq.genome-mapped.bam | \
  cut -f1 | sort -u > /tmp/bam_reads.txt
zcat examples/inputs/downsampled/EXAMPLE_SE.IP.umi.r1.fqTrTr.sorted.fq.gz | \
  grep "^@" | sed 's/^@//' | sort -u > /tmp/fastq_reads.txt
comm -23 /tmp/bam_reads.txt /tmp/fastq_reads.txt | wc -l  # should be 0
```
Expected: 0 (no BAM reads absent from FASTQ).
